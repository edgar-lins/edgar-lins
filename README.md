# Hi, I'm Edgar 👋

**Software Engineer @ JumpCloud** · Professional Services (Brazil) 🇧🇷

I build automation and tooling for **identity & device management** — the kind of work that turns painful, manual IT migrations into repeatable, reliable software. Most of my day is spent making messy real-world data move cleanly between systems (Intune · macOS MDM · JumpCloud) without breaking things.

I came into engineering through a systems analysis background and a lot of self-teaching, and I care about building software that other people can trust and reuse.

---

### 🔧 What I work on

- **Device & identity management automation** — endpoint/MDM workflows across JumpCloud, Intune, and macOS
- **Migration tooling** — I lean on an `extract → map → idempotent load` pattern, with crash-safe state so a failed run can pick up exactly where it left off
- **Reusable internal tools** — reconciliation, auditing, and cleanup scripts that started as one-off client work and became reference architectures
- **PowerShell** for endpoint and directory automation
